## Numbers

Times are in game ticks, 20 to a second. Energy is the engine's `core:energy`, the same unit
every mod's machines use. Recipes are shaped and made on the base game's crafting table; a
`#name` in a recipe is a tag, so any item with that tag works, including other mods' planks,
ingots and gems.
